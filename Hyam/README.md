# 🤖 الذكاء الاصطناعي — عرض تزامني | أ. هيام الزهراني

عرض للمعلمة على السبورة، وكل مجموعة معها آيباد. لما تنتقل المعلمة لشريحة فيها سؤال، يظهر السؤال على الآيبادات تلقائيًا، وإجابات المجموعات تظهر للمعلمة مباشرة في لوحة جانبية.
يستخدم **نفس مشروع Firebase** المستخدم في عرض أ. نجود (`firebase-config.js` نفسه)، ولكل معلمة غرفة مستقلة برمزها.

| الصفحة | لمن؟ |
|---|---|
| `index.html` | صفحة البداية (زر المعلمة وزر المجموعات) |
| `teacher.html` | المعلمة: العرض + لوحة الإجابات 📡 + النقاط 🏆 |
| `student.html` | الآيباد: لكل مجموعة جهاز |
| `lesson.js` | محتوى الدرس والشرائح والمجموعات (مشترك بين الصفحتين) |

> بدون إنترنت؟ `teacher.html` يشتغل كعرض عادي («عرض الدرس فقط»).

## إضافة أ. هيام (مرة وحدة فقط)
من Firebase Console ← Realtime Database ← Data ← تحت `teachers` أضيفي فرعًا جديدًا (مثل `202`):
```
teachers
 └─ 202
     ├─ name: "أ. هيام الزهراني"
     └─ pin:  "رقم سري من 4 أرقام"
```
الرمز `202` هو نفسه **رمز الفصل** اللي تكتبه الطالبات. لا تكتبين الرقم السري في أي ملف يُرفع على GitHub.

## في الحصة
- **المعلمة:** تفتح `teacher.html` وتدخل برمزها ورقمها السري، فيظهر رمز الفصل + رمز QR على شريحة البداية.
- **كل آيباد:** يفتح `student.html` (أو يمسح رمز QR) ويكتب رمز الفصل ثم يختار المجموعة.
- لوحة الإجابات: زر 📡 أو حرف **ج**. فيها: مؤقت 30/60 ث، كشف الإجابة على الأجهزة، نقاط تلقائية للإجابات الصحيحة (+1 للأسرع)، و +1 يدويًا.
- قبل كل حصة: 🏆 ← 🆕 حصة جديدة (يمسح الإجابات ويصفّر النقاط).

## تعديل الدرس
- المجموعات (الأسماء والألوان والعدد): `LESSON.teams` في `lesson.js`.
- أسئلة الآيباد تتكوّن تلقائيًا من الشرائح. لإيقافها في شريحة: `student:false`، ولسؤال مخصّص: `student:{ kind:'text', q:'نص السؤال' }`.
